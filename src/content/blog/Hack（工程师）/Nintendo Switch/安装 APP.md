**通过 DBI 拖拽安装任意 Switch 应用指南**
> **⚠️ 重要前提**：此方法仅支持在 Windows PC 上进行操作。亲测 macOS 系统无法正常挂载 MTP 或完成传输，请务必使用 Windows 电脑。
**1. 获取安装文件**
在网盘或相关资源库中下载目标应用的离线安装包（通常为「.nsp」、「.nsz」或「.xci」格式）。
**2. 连接 DBI**
在 NS 端打开 DBI，选择「Run MTP responder」，使用数据线将 NS 连接至你的 Windows 电脑。
**3. 拖拽安装**
Windows 电脑端会出现一个名为「Switch」的 MTP 驱动器。打开该驱动器，找到「5: MicroSD install」（表示安装到 TF 卡）。将下载好的应用安装文件直接拖入该文件夹内。
**4. 安装完成**
等待电脑端传输进度完成，NS 桌面即刻会生成对应应用的图标。
