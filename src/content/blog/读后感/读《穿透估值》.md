## 前言 读懂财报可以少亏钱，看透估值才能多赚钱

**重点**：作者邹佩轩（华源证券分析师、新财富白金团队核心成员）的立意是把学院派理论与实战经验公式打通：读懂财报只能少亏钱（防守），看透估值才能多赚钱（进攻）。全书四章：理论模型 → 实战模型 → 动态博弈 → 案例复盘。

**思考**：这句话把投资者分成两层——大部分人的瓶颈在财报层，少数人的战场在估值层。财报告诉你企业怎么样，估值告诉你市场在想什么；差的那一步，恰是超额收益的来源。

## 第1章 回望象牙塔中的理论模型：重视框架，淡化结果

**重点**：为教科书正名。DCF 模型是一种价值观而非计算器，它给出估值的第一性原理——企业价值等于未来自由现金流的折现：

```
V = Σ FCF_t / (1 + r)^t
```

投资组合理论把视角从个股拉到组合（收益-风险的优化）；CAPM 由此引申出风险定价假说：

```
E(R_i) = R_f + β_i × (E(R_m) − R_f)
```

**思考**：理论模型的正确打开方式是「重视框架，淡化结果」。CAPM 的 β 在实证中漏洞百出，但「风险应当被定价」塑造了整个市场的语言。把它当真理会亏钱，把它当地图会赶路。

## 第2章 实战常用模型：DCF 的变体与各种估值法

**重点**：DCF 的几种变体（两阶段/三阶段、FCFF 与 FCFE 之分）与相对估值法（PE/PB/EV/EBITDA）的适用场景与陷阱。折现率用 WACC，自由现金流从 EBIT 出发自算：

```
WACC = (E/V)×Re + (D/V)×Rd×(1−T)
FCFF = EBIT×(1−税率) + 折旧摊销 − 资本开支 − 营运资本追加
```

**思考**：实战的死穴从来不是「不会算」，而是参数——永续增长率 g 与折现率 r 的小数点后一位，就能让目标价天翻地覆。估值法是显影液：洗出来的是使用者的预期，不是企业的真相。

## 第3章 估值实战化：动态的投资过程与人性博弈

**重点**：估值是过程而非快照——价格围绕价值波动，但共识本身会反身性地改变价值。书中把交易行为与规则制度（筹码结构、涨跌停、减持规则）纳入估值，解释「低估」为什么可以更低估。

**思考**：这章呼应书名里的「博弈」。便宜不是买入的充分条件，便宜可能是一种均衡——市场在等催化剂打破均衡。搞清楚对手盘为什么卖给你，比算出目标价更重要。

## 第4章 经典案例复盘：透过行业差异寻找规律

**重点**：沿前三章框架做经典案例复盘，覆盖公用事业、消费、成长等不同行业，验证同一框架在不同行业的参数取值与失效边界。

**思考**：案例的价值不在结论而在过程——同一把尺子量公用事业和量成长股，量法完全不同。规律藏在差异背后：商业模式决定现金流的形态，现金流形态决定估值工具的选择。

## 结语

**重点**：估值体系三层——学院框架是地图，实战公式是工具，博弈思维是对手盘意识，缺一层框架就退化成精确的错误。

**思考**：读完记住的不是某个公式，而是一个态度：对精确保持怀疑，对框架保持忠诚。模糊的正确胜过精确的错误——但「模糊」必须建立在框架之上，否则只是随便。
