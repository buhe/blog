Calibre 的 **New Douban** 插件（通常指由 `fugary` 开发的版本）是目前获取中文图书元数据（封面、简介、评分等）最稳定、最好用的工具之一。因为豆瓣官方 API 已经停止对公众开放，该插件主要通过爬虫技术从豆瓣网页获取信息。
以下是详细的使用教程：
### 第一步：安装插件
由于该插件通常不在 Calibre 官方的「获取新插件」列表中，你需要通过手动下载安装。
1. **下载插件**：前往 GitHub 搜索 `fugary/calibre-douban`，在 **Releases** 页面下载最新的 `.zip` 文件（注意不要解压）。
2. **安装到 Calibre**：
	- 打开 Calibre，点击工具栏上的「首选项」(Preferences)。
	- 在高级选项栏点击「插件」(Plugins)。
	- 点击右下角的「从文件加载插件」(Load plugin from file)。
	- 选择你刚才下载的 `.zip` 文件，在弹出的安全警告中点击「是」。
	- **重启 Calibre** 以使插件生效。
---
### 第二步：配置插件
安装完成后，建议进行简单配置以确保搜索效果最佳。
1. **进入配置**：
	- 回到「首选项」-\>「插件」。
	- 在「元数据源插件」分类下找到 **New Douban**。
	- 点击「自定义插件」(Customize plugin)。
2. **设置偏好**：
	- **搜索设置**：你可以勾选是否搜索标签、系列信息、出版社等。
	- **评分转换**：豆瓣是 10 分制，Calibre 是 5 星制，插件通常会自动转换（例如 8 分转为 4 星）。
	- **测试连接**：确保插件能够正常访问豆瓣网页。
---
### 第三步：获取元数据
配置好后，你就可以开始为你的电子书更新信息了：
1. **选择图书**：在列表中选中一本书或多本书。
2. **下载元数据**：
	- 右键点击图书，选择「修改元数据」-\>「下载元数据和封面」。
3. **配置来源（关键点）**：
	- 在弹出的窗口中，点击左下角的「配置下载」。
	- 确保在「元数据源」列表中勾选了 **New Douban**。
