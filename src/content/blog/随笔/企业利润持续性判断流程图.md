### **科技类企业**
```plain text
  技术护城河是否稳固？
         │
      否 → 高风险（利润可能骤降）
         │
         ▼
  产品线是否有后续储备？
         │
      否 → 中风险（利润几年后或衰退）
         │
         ▼
  用户粘性/网络效应强吗？
         │
      否 → 中风险
         │
      是 → 低风险（利润较持续）
```
---
### **制造业企业**
```plain text
  行业格局：寡头还是分散？
         │
   分散 → 高风险（价格战激烈）
         │
         ▼
  是否有成本优势或品牌溢价？
         │
      否 → 中风险（易被替代）
         │
         ▼
  产品是否受周期波动影响？
     是 → 中风险
     否 → 低风险（利润稳定）
```
---
### **金融业企业**
```plain text
  风险管理是否稳健？
 (不良贷款/赔付率/杠杆水平)
         │
      否 → 高风险（利润不可持续）
         │
         ▼
  盈利模式是否稳定？
  （银行息差、保险长尾保费）
         │
      否 → 中风险（波动大）
         │
         ▼
  是否具备规模或资金成本优势？
         │
      否 → 中风险
      是 → 低风险（利润更稳）
```
---
### **🏁 输出结果**
- **低风险** → 利润高度可持续
- **中风险** → 利润部分可持续，受行业/产品/宏观影响
- **高风险** → 利润不可持续，可能大幅波动或衰退

### **🏁 使用方式**
1. 先确定公司属于 **科技 / 制造 / 金融**。
2. 在对应的表格里勾选 ✅ 或 ❌。
3. 我来帮你根据勾选结果，综合判断利润持续性：
	- ✅ 多 → **低风险（利润持续性强）**
	- ✅/❌ 一半 → **中风险（部分持续性）**
	- ❌ 多 → **高风险（利润不可持续）**
