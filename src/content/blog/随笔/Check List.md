- [ ] 至少完整阅读一份财报
- [ ] 用 Claude Code 生成一份分析报告，内容发给我
- [ ] 写一篇你的分析报告，内容发给我，我给你提几个关于基本面的问题引发你的思考

- [ ] **10年 PE 走势：** 目前是否处于低估区？市场定价逻辑是否发生根本性改变？若不期待估值（PE）的均值回归，企业内生净利润的增长能否单独支撑预期的投资回报？
- [ ] **Non-GAAP PE 对比：** 当前的 Non-GAAP PE 是否明显低于最近20年的平均 Non-GAAP PE？
- [ ] **自由现金流收益率：** 企业产生的自由现金流（FCF）对比其企业价值（EV）或市值，收益率是否具有吸引力（如无风险利率之上加上适当的风险溢价）？
- [ ] **反向思考与「价值陷阱」：** 市场为什么会给出如此低的估值？是暂时的宏观/行业逆风，还是企业基本面已经出现不可逆的永久性受损？
- [ ] **资产负债表健康度：** 有息负债率是否过高？流动比率和速动比率是否安全？是否存在大量难以变现的无形资产或商誉？是否有足够的现金储备应对行业寒冬？
- [ ] **盈利质量：** 净利润是否由真实的经营活动现金流支撑？（经营现金流净额是否长期大于或等于净利润？）是否存在频繁的非经常性损益粉饰报表？
- [ ] **资本支出要求：** 维持现有竞争地位是否需要持续、消耗大量现金的资本支出（Capex）？
- [ ] **竞争优势的持久性：** 企业是否拥有至少一种清晰的护城河（无形资产、转换成本、网络效应、成本优势）？该优势在未来10年是否可能被技术创新或新商业模式颠覆？
- [ ] **投入资本回报率：** 历史的 ROIC（投入资本回报率）或 ROE（净资产收益率）是否长期保持在高位（如15%以上）？
- [ ] **定价权：** 面对通货膨胀或原材料成本上升，企业能否在不流失市场份额的前提下，轻松将成本转嫁给消费者？
- [ ] **管理层诚信度：** 管理层过往的公开信或业绩指引是否诚实可信？在遇到困难时是否坦诚，还是习惯性寻找客观借口避重就轻？
- [ ] **资本配置能力：** 管理层如何处理多余的现金？是否在股价低于内在价值时进行股票回购？派息政策是否稳定合理？过往的并购（M&A）是否真正创造了价值，还是仅仅为了扩大规模而摧毁了股东财富？
- [ ] **利益捆绑：** 管理层及核心内部人士是否持有大量公司股份，与普通股东的利益深度绑定？
- [ ] **单一依赖风险：** 企业的收入是否过度依赖单一客户、单一供应商或单一宏观政策？
- [ ] **安全边际：** 即使对未来的自由现金流增长做出最保守的假设，目前的买入价格是否依然能提供足够的容错空间？
- [ ] **大客户集中与流失风险：** 公司的绝大部分营收是否高度依赖单一或极少数核心客户？这些大客户是否具备向上游整合、研发自用替代产品（In-house Development）的动机和资金能力？若大客户流失，估值模型是否留有了足够的安全垫？
- [ ] **核心技术依赖与知识产权风险：** 公司的底层产品架构或核心生产力是否受制于第三方的技术授权？是否存在可能动摇业务根基、导致停售或巨额索赔的重大法律诉讼、专利纠纷或反垄断调查？
- [ ] **地缘政治与单一市场暴露风险：** 公司的核心收入或关键供应链是否过度集中于特定国家或地区？该区域是否存在因贸易摩擦、技术出口管制或强烈的「本土替代」政策而导致的系统性退坡风险？
- [ ] **业务转型与「第二增长曲线」执行风险：** 当主营基本盘面临增长瓶颈或结构性衰退时，管理层规划的新业务线能否在规定时间内填补营收缺口？更关键的是，这些处于开拓期的新业务，其投入资本回报率和毛利率是否会大幅拖累公司历史整体的盈利中枢（Margin Dilution）？
- [ ] **行业周期性与供应链脆弱性：** 公司所处的行业是否已进入存量博弈阶段且极易受宏观经济周期波动影响？面对上游产能约束（如零部件短缺）或下游需求骤降，公司是否具备足够的产业链话语权将压力转移？传统的护城河是否正在被采取不同技术路线或激进定价的竞争对手瓦解
- [ ] **检查格雷厄姆数字，注意资产性质错配：**格雷厄姆数字的有效性建立在公司拥有扎实的**有形资产**之上（如工厂、存货、土地）。而互联网公司的资产负债表中，包含了大量的商誉、无形资产以及对外股权投资。如果发生极端清算，这些资产的实际变现折扣率极高，其真实的「有形账面价值」远低于 PB 倒退的。
- [ ] 「SBC 调整后自由现金流」是否为正
- [ ] 计算一下该公司的清价格，包括无形资产（品牌、专利等）
- [ ] 是不是价值陷阱
